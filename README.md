# Glacier

Glacier is a winter-themed streaming web app with:

- Full Glacier branding and icy UI
- Frosted glassmorphism in dark and light modes
- Hero spotlight, Trending, New Releases, Continue Watching, Top Rated, and Watchlist rows
- Search with lightweight suggestions
- Built-in video playback and persisted watch history/watchlist (localStorage)

## Run locally

Open `index.html` in your browser.
